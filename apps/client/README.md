# apps/client

Aplicação React pública, sem autenticação. Cardápio, montagem de pedido (adicionais e observações) e pagamento via Pix. Roda tanto no navegador do celular do cliente (acesso por QR code na mesa) quanto em modo quiosque num tablet Android: é o mesmo código, a diferença é configuração de implantação, não uma versão separada.
